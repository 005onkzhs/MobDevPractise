 Мобильное приложение Заметки
 Описание проекта
Данный проект представляет собой мобильное приложение для создания и управления персональными заметками, разработанное в рамках практического задания по дисциплине Разработка мобильных приложений под ОС Android. 

Приложение реализовано на языке Kotlin с использованием классической концепции Android View и XML-разметки. В проекте соблюдены все требования к архитектуре, обработке пользовательского ввода, передаче данных между компонентами и логированию.

 Технические характеристики
- Язык программирования: Kotlin
- Минимальная версия SDK: API 26 (Android 8.0 Oreo)
- Целевая версия SDK: API 36
- Архитектура интерфейса: Android XML-layouts (View System)
- Основные контейнеры компоновки: LinearLayout, RelativeLayout, ScrollView
- Навигация: Явные Intent (Explicit Intents) и Activity Result API

 Структура и архитектура приложения
Приложение состоит из трех основных экранов (Activities):

1. MainActivity (Экран авторизации)
   Начальный экран приложения. Содержит форму ввода имени пользователя, кнопки подтверждения и очистки текстового поля. Реализована проверка на пустое значение ввода. При успешном вводе происходит переход на экран списка с передачей имени пользователя через Intent.

2. ListActivity (Главный экран списка заметок)
   Экран отображает приветствие с именем пользователя и динамический список созданных заметок. Каждая заметка представлена в виде отдельного карточного блока с уникальным стилем. На экране присутствуют кнопки перехода к созданию новой заметки и кнопки выхода из профиля.

3. AddNoteActivity (Экран создания заметки)
   Экран содержит многострочное поле ввода для текста новой заметки. Реализована валидация на наличие текста. При сохранении данные передаются обратно в ListActivity с использованием setResult, после чего новая заметка сразу появляется в общем списке.

 Логирование и отладка
В приложении реализовано полное логирование жизненного цикла всех Activity, а также ключевых пользовательских действий с использованием класса android.util.Log.

Фиксируемые события:
- Создание и изменение состояний экранов (onCreate, onStart, onResume, onPause, onStop, onDestroy)
- Успешная авторизация и попытки ввода пустого имени (Log.i, Log.w)
- Навигация между экранами (Log.d)
- Сохранение новых заметок и отмена ввода (Log.i)

Пример выгрузки логов работы приложения находится в репозитории по пути: logs/logs.txt
 Размещение и сборка
Готовый установочный файл приложения в формате APK прикреплен к официальному релизу проекта в разделе Releases текущего репозитория.
